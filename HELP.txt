COLMAP Tracker — standalone desktop application

START
Double-click Start_Tracker.cmd. It opens a dedicated PySide6 application with
an embedded OpenGL viewport, without the Blender interface. Each launch opens
an empty project. Click Prepared scene to load the configured SCENES example.

WORKSPACE
Left: tracking settings and output directory.
Middle: original video or solved image sequence.
Right: colored point cloud, camera trajectory and current camera, with Z up.
Bottom: timeline, playback and processing log.
Left drag orbits; right/middle drag pans; wheel zooms. Fit scene resets the view.
Points and Camera path toggles control visibility. Settings panel can scroll.

NEW TRACKING
Choose Open video, set COLMAP/GLOMAP, FPS, image size and GPU, then Start tracking.
First seconds = 0 processes the entire video; 8 is useful for a short test.
A static mask uses black to exclude and white to retain pixels; dimensions
must match the source frames. Moving video masks are not implemented.
Stop terminates the current process and retains partial output.
Every run has a new project directory, settings.json and tracking.log.
Failed runs are not marked complete. The largest disconnected model is loaded.

PLAYBACK / IMPORT
Source video plays the original clip, muted. Solved frames use the extracted
sequence at Tracking FPS. Unregistered frames display no solved camera.
Tracking FPS resamples to an integer rate; it can differ from the source rate.
Import TXT model loads cameras.txt, images.txt and points3D.txt. Numbered frame
names are required. Set Import FPS before loading an external reconstruction.
Our project folders read FPS from settings.json. The prepared scene uses
30000/1001 fps. Missing images do not prevent 3D preview.
Playback follows elapsed video time and skips overdue frames to avoid drift.
Solved images are prefetched in the background; pausing/seeking shows the exact
selected frame. The camera stays paired with the displayed image. Graph caching
and GPU lens correction reduce preview work without changing the source media.

EXPORT
Export .blend runs Blender in the background without opening its interface.
It saves native point geometry, camera animation and trajectory. Images stay
linked to the project folder. Interpolation between keyframes is not a solve.
The standalone point renderer is not embedded in the Blender file.

DEPENDENCIES / LIMITATIONS
This is a working prototype, not a packaged portable executable. config.json
uses existing RGBMoCap Python/PySide6 packages and existing COLMAP 3.12.3,
GLOMAP, FFmpeg and Blender executables. No RGBMoCap files or packages are changed.
Blender is needed only for .blend export. OpenGL 3.3 is required for 3D preview.
Point preview is capped at 200,000 points; full reconstruction output is kept.
Z-up conversion is consistent for geometry and cameras; it is not physical
 gravity estimation or automatic ground-plane alignment.
The old sample has original distorted frames; new solves use undistorted ones.
Manual 2D track editing and moving-object tracking are not implemented.
The old Blender prototype remains in tracker.py. The standard launcher now
starts desktop.py.

SCENE TOOLS
Scene & objects has an object tree. Show hides a primitive in video and 3D;
Lock prevents editing/picking it in 3D. Locked objects still follow Whole scene.
Rename (F2), Duplicate (Ctrl+D), Delete and Frame selected (F) are available.
Visibility and locks are saved and exported. Edit > Undo/Redo (Ctrl+Z /
Ctrl+Shift+Z) shares a history for objects, floor and camera corrections.
One gizmo drag is one step. New/open resets history.
Click the corner axis gizmo (+/-X, +/-Y, +/-Z) to switch to an orthographic view.
Dragging in Orbit returns to perspective. Z remains the world up reference.
Scene & objects opens the transform panel. Choose Whole scene to move/rotate/
scale the reconstruction, camera, trajectory and all added objects together.
Position/Rotation XYZ fields are exact; Move and Rotate modes allow left-drag
editing of the selected target. Right-drag pans the viewport without editing.
Whole-scene rotation uses the reconstruction origin as pivot. Object transforms
are local to that scene root. Use Reset transform to restore the selected target.
Add Cube or Cone, then select it in Transform target. The cone tip points down
(-Z), and the object's origin/pivot is exactly at its tip (local 0,0,0).
Save scene layout stores transforms and primitives as JSON; Load restores them.
The original reconstruction files remain unchanged. Export .blend includes
all objects and transforms under Tracker Scene Root.

OBJECT OVERLAY
Object overlay shows the added objects in solved images and matching source
video. Its slider controls opacity. Projection uses the solved camera and lens
model, including supported radial/OpenCV distortion. Missing camera poses have
no overlay. The scene-root transform affects camera and geometry together, so
moving Whole scene deliberately preserves image alignment. Move an individual
object to change its placement in the image. This is a preview overlay without
occlusion against real-world objects; sparse points do not provide a depth mesh.

DIRECT SELECTION AND TRANSFORM GIZMOS
Click a cube or cone in the 3D viewport to select the nearest object surface.
Selection is synchronized with the Scene & objects panel and shows a gizmo
at the actual origin (the tip for cones). New objects start in Move mode.
E / Move (G also works): drag a colored X, Y or Z arrow to translate along that axis only.
R / Rotate: drag a colored ring to rotate around that axis and object origin.
T / Scale: drag the square outward/inward to scale uniformly around the origin.
E/R/T work across the window, except when editing text/numbers, choosing a combo
value, using a dialog, picking floor points, or already dragging a gizmo.
Global uses world axes; Local uses the object's rotated axes. Select this in
Scene & objects > Gizmo axes. Parent scene rotation and scale are respected.
Escape during a drag restores the transform and preserves selection.
Clicking empty space selects Whole scene. Dragging empty space orbits without
moving objects; right/middle drag pans. The corner gizmo still changes views.
Image overlays and Blender export use the same edited transforms.

CAMERA KEYFRAME GRAPH
Space toggles playback in Source video and Solved frames. It also works when
the 3D viewport or timeline has focus. Text/numeric inputs keep normal typing;
holding Space does not repeatedly toggle playback.
When playback reaches the end, Space or Play restarts from the beginning.
Left/Right step; Home/End jump to ends; Frame jumps to a number. In/Out (I/O)
set a range; Clear resets it; Loop repeats it; speed is 0.25x to 2x.
Source indexing uses ffprobe.exe beside FFmpeg. Stepping enables after indexing.
Image wheel zooms, middle/right drag pans. Fit / 100% reset scale; Loupe magnifies
under the pointer; Hide overlays shows the clean picture. Help lists shortcuts.
Below the timeline, enable Keyframe graph. Choose Position XYZ, Translation XYZ
(signed units/frame), Translation total (magnitude), or Rotation jump (degrees/frame).
Translation XYZ: X red, Y green, Z blue. XYZ / X only / Y only / Z only isolates
an axis and rescales the plot. Negative values indicate the opposite direction.
The first camera has a zero baseline; frame gaps normalize the displacement and
remain gaps in the plotted lines. Dashed = original solve;
solid = current result; amber marks = corrected frames. Click a frame to select
it. Around frame +/-50 zooms the time range. Gaps mean unsolved cameras.
Edit X/Y/Z and RX/RY/RZ, then Apply pose. Camera values use the Z-up reconstruction
coordinates. Only this frame locks editing to the chosen solved camera frame.
Other frames can be previewed but their pose controls are read-only. Use current
frame retargets the lock; Go to edit frame returns to its target. Turning it off
follows the selected frame, still changing only one camera. The lock resets when
opening a model/project. It targets solved frames; lower tracking FPS can map
several source-video frames to one camera. Camera values use reconstruction
coordinates. You can also drag the X/Y/Z and RX/RY/RZ labels with the horizontal
arrows: changes apply live without Apply pose. Shift gives 10x finer movement;
Drag speed selects 0.1x/1x/10x. One completed drag = one Undo step. Esc, focus loss
or switching frames cancels the unfinished drag. Dragging pauses playback.
Save/autosave wait until the drag finishes. These are camera pose corrections,
not manual 2D marker edits or a new solve. The values use reconstruction
coordinates before the Whole scene transform. Interpolate +/-5 preserves the
corrected centre and blends five frames on each side to fixed outer cameras.
Increase the range with the +/- frames control (5 to 100). Inspect outer anchors
first (normally centre +/-6). Position is linear; rotation takes the shortest arc.
Missing solved frames are skipped; clip ends remain fixed and shorten the range.
Existing corrections inside the neighbour range are replaced. This explicit
range action also works at the pinned centre with Only this frame enabled.
The whole range is one Undo/Redo step; pose fields/drags remain single-frame edits.
Reset frame restores the original; Undo reverses edits. The corrected camera
and trajectory are used in the preview and Export .blend.
Save corrections / Load corrections use a separate JSON file tied to this exact
model. Source COLMAP files remain untouched. Save corrections separately from
the scene layout. An unsaved-changes prompt protects edits on close/model reload.

FLOOR GRID
Floor grid displays the world XY plane in Solved frames and matching source
video. Step changes spacing; Z changes floor height in both video and 3D views.
Use Whole scene transforms to align the solve to the grid. This guide does not
detect the physical floor, has no real-scene occlusion and is not exported.

POINT CLOUD / SURFACE MESH
Generate 3D mesh in the main left panel reuses the loaded solve for this video,
or runs tracking followed by meshing automatically. Stop cancels both stages.
In the video toolbar, Points, Mesh and Objects toggle geometry independently.
The slider controls geometry opacity. Shading opens Solid, Vertex color,
Wireframe, Solid + wire, Normals, and Smooth normals (off = flat shading).
These modes affect surfaces and primitives in video and 3D. Video point colors
can be RGB, Solid or Depth; size is adjustable. Vertex color is not a texture.

Build surface mesh runs COLMAP Poisson meshing on filtered sparse points.
Mesh detail sets resolution; Max input points sets sampling; Density trim
removes weakly supported regions. Cancel mesh stops the worker and its child.
This is an approximate surface, not a dense stereo reconstruction: missing
regions may become holes or inferred geometry. Source COLMAP files stay intact.
Completed surfaces are saved under projects/meshes and reload with the model.
Load saved mesh accepts matching .npz files. Export mesh .ply bakes the scene
transform into Z-up coordinates; Export .blend also includes the surface mesh.
The surface moves with Whole scene. Geometry layers occlude one another, but
filmed objects do not independently occlude the overlay.

FILE MENU / PROJECTS
The application window is named ALIEN TRACKER; folder/repository names are unchanged.
File: New project (Ctrl+N), Open video (Ctrl+O), Open project (Ctrl+Shift+O),
Save project (Ctrl+S), Save project as (Ctrl+Shift+S), Exit (Alt+F4).
Projects (*.tracker.json) store settings, objects, scene/floor transforms,
camera corrections, mesh references, and view/timeline state. Video, frame
images and reconstruction files are referenced rather than embedded. Keep these
assets available when reopening or moving the project. Unsaved edits have a
Save/Discard/Cancel prompt. New project clears the UI without deleting assets.

FLOOR ALIGNMENT
Align floor > Pick floor points: click 3 or more spread-out points from one
floor plane in the 3D viewport. Click a marker again to deselect. Drag to orbit;
use the axis gizmo or zoom for a better view. Escape leaves picking mode.
Align floor to Z = 0 fits the selected plane and moves/rotates the whole scene,
including cameras, points, mesh and objects, preserving their video alignment.
Edit > Undo / Undo last edit reverses the last project edit. Save project preserves
the resulting alignment. Collinear/non-planar selections are rejected.

RECOVERY / THEME
Unsaved work autosaves every 30 seconds to projects/.recovery separately from
the manual project. File > Recover autosave restores interrupted sessions; save
the restored project. Active sessions are excluded. Startup remains empty.
Recent projects lists recent files. Opening moved assets offers to locate them;
Save preserves the corrected paths. Media files are still externally referenced.
Shadow-inspired styling provides neutral dark panels, light text and blue
selection. Scene & objects includes icons for scene components and editing tools.
Static primitive geometry is shared by the video overlay and 3D viewport, with
GPU buffers reused until an object or shading setting changes. This reduces
playback overhead while preserving the original video and calibrated projection.

TRACK DATA (P1 / FIRST STEP)
Load a reconstruction, then click Track data below its statistics.
The table lists registered frames, image IDs and measured/linked/unlinked points.
Double-click a row or use Go to selected frame to open that solved frame.
Invalid means a broken data reference or invalid coordinate, not pixel error.
Unlinked features are normal: they have no reconstructed 3D point.
Times use the extracted frame number and tracking FPS, not source video indices.
The full measurements remain separate from viewport sampling and scene edits.
Large models take longer to import and use more memory; the prepared scene takes
about 16 seconds locally. Projects reference the original model files as before.
Manual 2D correction and aggregate error graphs are later steps.

TRACK ERROR OVERLAY (P1 / SECOND STEP)
Choose Solved frames and enable Track error above the image.
Circle = measured point; cross = projected 3D point; line = pixel error.
Green <= 1 px; yellow <= 3 px; red > 3 px, measured in model-image pixels.
Current camera includes manual corrections. Original solve uses the imported pose.
Scene/floor transforms and zoom do not change pixel error. Hide overlays hides it.
Options opens minimum error and maximum markers (default 1000); highest errors
are prioritised. Invalid/untriangulated observations are excluded; points behind
the camera are reported as not projectable. Settings are saved with the project.
Source video uses different frame timing: switch to Solved frames for measured
diagnostics. Existing 3D overlays remain available on source video.
